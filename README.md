# Skills

Standalone skills installed by directory name from `skills/`.

## Install

Install one skill:

```sh
./install.sh pr
```

Install every available skill:

```sh
./install.sh --all
```

Skills are copied to `~/.claude/skills/`.

## Uninstall

Remove one skill:

```sh
./install.sh --uninstall pr
```

Remove every available skill:

```sh
./install.sh --uninstall --all
```
